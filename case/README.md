# ADD2go Empfänger-Gehäuse

## Übersicht

3D-Druck-Gehäuse für den ADD2go-Empfänger im Radlader. Besteht aus
Hauptgehäuse, Deckel mit Display-Ausschnitt sowie einer Kugelgelenk-Halterung
zur Befestigung an einer beliebigen Stelle im Fahrerstand.

## STL-Dateien

| Datei | Funktion |
|---|---|
| `boxv2.stl` | Hauptgehäuse für ADD2go-Platine + ESP32 |
| `deckel v2.stl` | Deckel mit Display-Ausschnitt |
| `anschraubplatte_neu.stl` | Befestigungsplatte zum Anschrauben am Fahrzeug |
| `Ball-joint_mit_bohrung.stl` | Kugelgelenk-Aufnahme (mit Bohrung für die Schraube) |
| `Ball-joint_screwv1.3.stl` | Schrauben-Element des Kugelgelenks |
